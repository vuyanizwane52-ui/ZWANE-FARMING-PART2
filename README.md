# Zwane Farming, WEDE5020 Part 2

## Project purpose
This Part 2 website demonstrates the CSS skills assessed in the WEDE5020 rubric. The project uses HTML and one shared external CSS stylesheet across all pages. The visual styling is deliberately clear so the assessed CSS properties are easy to see in the finished website.

## Pages
- index.html, home page
- about.html, organisation and farm information
- livestock.html, livestock information
- crops.html, crop production information
- sustainability.html, responsible farming information
- gallery.html, farm image gallery
- contact.html, contact details and enquiry form

## CSS approach
The project uses one external stylesheet at css/style.css.

Visible CSS examples include:
- Default styling for body, images, links, buttons, forms and sections
- Typography using Arial for body text and Georgia for headings
- Font sizes using rem and clamp()
- Flexbox for the header and footer
- CSS Grid for cards, content areas, statistics, gallery and the form
- Background colours, borders, border-radius, box shadows and spacing
- Navigation hover, active and focus-visible states
- Button hover and active states
- Card hover and active states
- Form focus, valid and invalid states
- Three responsive media-query breakpoints
- Responsive navigation, layout, typography and images


## Responsive breakpoints
980px, tablet and small desktop adjustments
760px, mobile layout adjustments
520px, small mobile adjustments

## Responsive images
The HTML uses picture, srcset and sizes. The CSS uses max-width, object-fit and responsive containers.
