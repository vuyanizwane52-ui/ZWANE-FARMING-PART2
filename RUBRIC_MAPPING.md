# Part 2 Rubric Mapping

## Feedback for Part 1, 10 marks
CHANGELOG.md includes a dedicated section for the lecturer's Part 1 feedback. The exact lecturer feedback must be inserted before submission.

## External stylesheet, 10 marks
All seven HTML pages link to the same external file, css/style.css.

## Default CSS styles, 5 marks
The stylesheet contains a reset, CSS variables, body defaults, image defaults, link defaults, form defaults, shared containers and section spacing. These styles are visible across the entire site.

## Typography, 5 marks
The site uses Arial for normal text and Georgia for headings. Font sizes, weights, line heights, letter spacing and text colours are set for different content levels. clamp() and relative units support responsive typography.

## Layout structure, 5 marks
Flexbox is used in the header, navigation and footer. CSS Grid is used in the main content layouts, cards, gallery, statistics, sustainability cards and contact form.

## Decoration and colour, 5 marks
The site uses a clear green, cream and neutral colour system. The CSS visibly applies borders, border-radius, shadows, button backgrounds, section backgrounds, overlays and spacing.

## Pseudo-classes, 10 marks
The stylesheet uses :hover, :active, :focus-visible, :focus, :valid and :invalid. These states are applied to navigation links, buttons, cards, gallery items, links and form controls.

## Media queries and breakpoints, 5 marks
Three breakpoints are provided at 980px, 760px and 520px.

## Responsive layout, 5 marks
Multi-column layouts reduce to two columns and then one column as the screen becomes smaller. Header and footer content also wrap or stack.

## Responsive typography, 5 marks
Heading and lead-text sizes use clamp(). Relative units and media queries adjust supporting text on smaller screens.

## Responsive navigation, 5 marks
The desktop navigation uses a flex row. It wraps at 980px, changes to a two-column grid at 760px and becomes a single column at 520px. JavaScript is not required.

## Responsive images, 5 marks
picture, srcset and sizes are used in the HTML. object-fit and max-width are used in CSS so images fit their containers at different widths.
