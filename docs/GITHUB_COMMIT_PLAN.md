# Suggested GitHub Commit Plan

Use real commits that match the work completed. A suitable sequence for this project is:

1. `Create Part 2 page structure`
2. `Add shared external stylesheet`
3. `Style default typography and desktop layout`
4. `Add colours cards and interactive states`
5. `Add tablet and mobile media queries`
6. `Add responsive image sources`
7. `Remove JavaScript and make navigation CSS-only`
8. `Update README changelog and rubric mapping`
9. `Add final desktop tablet mobile screenshots`

Do not create fake commits. The final Git history should show the work you genuinely completed.
